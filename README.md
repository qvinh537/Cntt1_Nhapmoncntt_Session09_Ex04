## Phần 1: Phân tích bài toán
Giải thích tại sao Markdown lại giúp AI xử lý tài liệu nhanh hơn và chính xác hơn dựa trên số lượng Token.

Vì: Có nhiều app code có những dòng code rất rối và tốn token nhưng markdown sử dụng kí hiệu tối giản giúp nhìn ngắn gọn hơn,
Sử dụng token ít hơn giúp cho máy chạy nhanh hơn,
và với lượng token ít cùng với dòng code ngắn gọn giúp cho AI đọc được bài nhanh hơn dễ hiểu hơn và đưa ra kết quả nhanh hơn

## Phần 2. So sánh & Đánh giá
||Markdown|HTML|
|-|-|-|
|Số lượng ký tự và token|Thấp giúp tối ưu với cú pháp đơn giản và loại bỏ các dòng code dư thừa|Cao chứa nhiều code và cú pháp khó hiểu|
|Độ dễ đọc|Cao có thể đọc trực tiếp mã nguồn|Thấp khó đọc vì có nhiều các thẻ mã hóa ngắt quãng|
|Tốc độ xử lí AI| Nhanh do dùng ít token và kí hiệu được đơn giản hóa giúp AI đọc bài nhanh hơn| Chậm do có nhiều lệnh code phức tạp và ngắt quãng khiến quá trình đọc của AI bị hạn chế|
|Khả năng biểu diễn định dạng| Đủ cho các tài liệu|Cực kỳ chi tiết và linh hoạt, hỗ trợ tùy biến giao diện kiểu dáng (CSS) và hành vi (JavaScript)|
